# ⚛ فيزياء التوجيهي التفاعلية

نسخة تفاعلية من **كتاب الفيزياء للصف الثاني عشر (فلسطين)** — مبنية عشان الطالب يفهم المادة بدون ما يتغلّب.

## شو فيها؟
- **10 فصول كاملة** (الميكانيكا، الكهرباء المتحركة، الكهرومغناطيسية، الفيزياء الحديثة).
- **شرح مبسّط** لكل فكرة ("الفكرة ببساطة")، ثم التعريف والقانون بشكل واضح.
- **أمثلة الكتاب محلولة خطوة بخطوة** — الطالب بيكشف الحل خطوة خطوة بعد ما يحاول.
- **أكثر من 20 محاكاة تفاعلية** (تصادمات، عزم، دارات، كيرشوف، مجالات مغناطيسية، سيكلترون، مولد، ظاهرة كهروضوئية، طيف الهيدروجين، طاقة الربط…).
- **أسئلة الكتاب (الفصول والوحدات)**: اختيار من متعدد بتصحيح فوري وشرح، والأسئلة المقالية مع حلولها.
- **حفظ التقدّم** على جهاز الطالب، **وضع ليلي**، ويشتغل ممتاز على **الموبايل**.
- يعمل **بدون إنترنت** تقريباً (مكتبة KaTeX للمعادلات موجودة داخل المشروع؛ فقط الخط العربي من Google Fonts).

## النشر على GitHub Pages (مجاناً)
1. اعمل Repository جديد على GitHub (مثلاً `physics12`).
2. ارفع **محتويات** هذا المجلد (`index.html` ومجلدي `chapters` و `assets` وملف `.nojekyll`) إلى جذر الـ Repository.
3. من **Settings → Pages**: اختر `Deploy from a branch`، الفرع `main` والمجلد `/ (root)`، ثم Save.
4. بعد دقيقة بيصير الموقع على: `https://<اسمك>.github.io/physics12/`

## هيكل الملفات
```
index.html            ← الصفحة الرئيسية (الوحدات والفصول والتقدّم)
chapters/ch1.html …   ← الفصول العشرة
assets/style.css      ← التصميم (فاتح/ليلي، RTL، موبايل)
assets/app.js         ← الاختبارات، الحلول خطوة بخطوة، التقدّم، الفهرس
assets/katex/         ← مكتبة كتابة المعادلات (محلية)
```

## ملاحظات
- المحتوى مبني على الكتاب المقرر من وزارة التربية والتعليم الفلسطينية، والنسخة هاي **تعليمية مجانية وغير رسمية**.
- بعض الأسئلة بالكتاب بتعتمد على أشكال؛ تم وصف الشكل نصياً بالسؤال. إذا لقيت أي خطأ، افتح Issue.


## الإضافات الجديدة
- **بنك الأسئلة الوزارية** (`bank/ch1.html` … `bank/ch8.html`): أسئلة امتحانات الثانوية العامة 2017–2025 مصنفة حسب الفصل، مع الإجابات والشرح، وتصفية حسب السنة والنوع، واختبار عشوائي من 10 أسئلة.
  المصدر: ملف «تصنيف أسئلة الثانوية العامة» لمجموعة فيزياء فلسطين… سؤال وجواب (مراجعة أ. أمجد شهاب).
- **ورقة القوانين** (`laws.html`): كل القوانين مرتبة حسب الوحدة، وجاهزة للطباعة على A4.
- الخطوط (Cairo و Lateef) مضمّنة داخل `assets/fonts`، فالموقع يشتغل بدون إنترنت.
